# Чек-лист: превращаем сессии Claude Code в коммиты и PR

Используется, когда есть паттерн: много сессий с Claude Code, но мало коммитов/PR. Помогает разобраться, где теряется прогресс, и закрепить привычки.

## 1. Фиксировать промежуточные результаты
- [ ] Коммичу даже неполный/экспериментальный код в ветку `wip/...` или `experiment/...`
- [ ] Правило: получил рабочий кусок — сразу `git add -p` + `commit`, не жду "пока всё будет готово"
- [ ] Не держу незакоммиченные изменения дольше одной сессии

## 2. Сохранять контекст между сессиями
- [ ] В конце сессии прошу Claude Code написать краткое резюме: что сделано / что осталось / какие решения приняты и почему
- [ ] Резюме сохраняю в `NOTES.md` или черновике описания PR
- [ ] Новую сессию начинаю с вставки этого резюме, а не с нуля

## 3. Разбивать задачу на мелкие итерации
- [ ] Перед началом работы декомпозирую задачу так, чтобы одна сессия = один коммит
- [ ] Если задача явно не влезает в одну сессию — заранее фиксирую точки, где можно остановиться и закоммитить

## 4. Ограничивать зацикливание на одной проблеме
- [ ] Если один и тот же баг/фича открывается 3+ раза без прогресса — останавливаюсь
- [ ] В этом случае: пишу тест, формализующий проблему, ИЛИ прошу Claude предложить 2-3 альтернативных подхода вместо продолжения того же пути

## 5. Разделять "консультацию" и "работу над кодом"
- [ ] Осознанно решаю в начале сессии: это разговор/исследование или сессия с целью довести до коммита
- [ ] Не считаю консультационные сессии "недоработанными" — это нормальный режим использования

## 6. Открывать draft PR раньше
- [ ] Открываю draft PR в начале работы над задачей, а не в конце
- [ ] По мере готовности коммитов из сессий Claude Code добавляю их в draft PR, не откладывая до "финального" пуша

## 7. Ретроспектива (ежедневно/еженедельно)
- [ ] Смотрю: сколько было сессий, сколько из них закончились коммитом
- [ ] Если процент низкий — разбираю, на каком этапе теряется прогресс:
  - [ ] не понял задачу
  - [ ] застрял в реализации
  - [ ] не хватило времени довести до конца
