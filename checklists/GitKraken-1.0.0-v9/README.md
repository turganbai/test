# GitKraken Claude Plugin

This plugin gives Claude AI access to your real Git and project context: commits, branches, pull requests, and issues across every repo you work in. Ask the agent a question about your work, and it answers from what's actually in your history and your trackers, not what it can guess from the open file.

Works with GitHub, GitLab, Azure DevOps, Bitbucket, and Jira.

## What you need

- Claude Code CLI: >2.x+
- Claude Desktop: >1.1.x+

## Getting started

- Claude Code CLI: Run `claude plugins install gitkraken` in your terminal to install the plugin.
- Claude Desktop: Go to Settings > Plugins > Marketplace, search for "GitKraken", and click the Install button.

## Using the plugin

Once connected, just ask the agent anything about your Git repos, branches, commits, pull requests, issues, and more. Here are some example prompts to get you started:

```
Show me issues assigned to me
```

```
Show me pull requests in progress
```

```
Who last modified this file
```
